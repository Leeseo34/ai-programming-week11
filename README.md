# ai-programming-week11
# 성적 관리 프로그램

## 1. What (무엇을 하나요?)
CSV 파일에서 학생 이름과 점수를 읽어 유효한 성적 데이터만 추출하는 프로그램입니다.

## 2. Why (왜 만들었나요?)
실제 CSV 파일에는 빈 값, 잘못된 점수, 형식 오류 등이 포함될 수 있습니다. 이러한 데이터를 처리하고 올바른 성적 데이터만 사용할 수 있도록 하기 위해 만들었습니다.

## 3. How (어떻게 사용하나요?)

### 실행
python load_scores.py


### 테스트 실행
pytest


## 4. 테스트

pytest를 사용하여 테스트를 수행합니다.
pytest


정상 입력, 예외 처리, 경계값(0점, 100점, 101점)에 대한 테스트를 포함합니다.

## 5. 파일 구성

- load_scores.py : CSV 파일을 읽어 성적 데이터를 처리하는 프로그램
- test_load_scores.py : 직접 작성한 테스트 코드
- test_ai_A.py : AI에게 코드를 제공하여 생성한 테스트 코드
- test_ai_B.py : AI에게 명세를 제공하여 생성한 테스트 코드
